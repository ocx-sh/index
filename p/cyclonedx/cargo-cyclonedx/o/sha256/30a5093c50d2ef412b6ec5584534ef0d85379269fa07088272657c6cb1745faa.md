# cargo-cyclonedx

[cargo-cyclonedx](https://github.com/CycloneDX/cyclonedx-rust-cargo) is the
official OWASP CycloneDX plugin for Cargo. It reads a Rust project's manifest
and dependency graph and emits a valid CycloneDX Software Bill of Materials
describing every crate the build pulls in — name, version, license expression
and package URL (`pkg:cargo/<name>@<version>`) per component.

Run it as a cargo subcommand (`cargo cyclonedx`) inside any workspace. `--format
json` or `--format xml` picks the encoding, `--spec-version` selects the
CycloneDX specification level (`1.3`, `1.4`, `1.5`), and `--describe` chooses
the granularity: one SBOM for the whole crate, one per binary, or one per Cargo
target. `--all` lists the full transitive dependency set while `--top-level`
restricts it to direct dependencies, `--no-build-deps` drops build-time crates,
and `--all-features` / `-F` / `--no-default-features` make the emitted graph
match the feature set you actually ship. `SOURCE_DATE_EPOCH` is honoured for
reproducible output.

## What's included

- **cargo-cyclonedx** — the SBOM generator. Invoke it as `cargo cyclonedx
  --format json --all` from a project root, or directly as `cargo-cyclonedx
  cyclonedx …` (the subcommand token is required either way — it is what cargo
  passes as `argv[1]`).

The mirrored archives also carry upstream's `LICENSE`, `README.md` and
`CHANGELOG.md` alongside the binary.

> **Requires a Cargo toolchain on `PATH`.** cargo-cyclonedx shells out to
> `cargo metadata` to read the project graph, and to `rustc -vV` to determine
> the default target. It is a plugin for an existing Rust installation, not a
> standalone SBOM scanner.

## Install with ocx

```sh
ocx install ocx.sh/cyclonedx/cargo-cyclonedx
```

```sh
# or pin a specific version
ocx install ocx.sh/cyclonedx/cargo-cyclonedx:0.5.9
```
