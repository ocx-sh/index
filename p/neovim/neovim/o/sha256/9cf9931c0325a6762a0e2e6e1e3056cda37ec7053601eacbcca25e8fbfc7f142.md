# Neovim

Neovim is a Vim fork focused on extensibility and usability. It keeps Vim's
modal editing model and ecosystem compatibility while modernizing the core:
a built-in Lua runtime, an embeddable RPC API, a native Language Server
Protocol client, and asynchronous job control. It runs as a terminal UI and
can also be driven as a headless editing engine.

## What's included

- **nvim** — the Neovim editor, with the bundled runtime (Lua plugins, syntax,
  ftplugins) and shared libraries
