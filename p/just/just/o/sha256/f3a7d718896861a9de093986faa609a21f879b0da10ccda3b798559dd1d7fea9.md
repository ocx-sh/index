# just

[just](https://just.systems) is a handy command runner. It reads a `justfile`
in your project directory and lets you define and run project-specific commands
(called "recipes") with a clean syntax. It is a modern alternative to `make`
for task automation — no complex dependency graph, no tab indentation quirks,
just named commands with arguments, default values, string interpolation,
conditional logic, and cross-platform shell support.

## What's included

- **just** — the command runner binary. Run `just <recipe>` to execute a
  recipe from the `justfile` in the current or parent directory. Run `just --list`
  to see all available recipes, or `just --evaluate <var>` to inspect a variable.
