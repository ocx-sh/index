# lsd

[lsd](https://github.com/lsd-rs/lsd) (LSDeluxe) is a rewrite of GNU `ls` with
colors, icons and a few extra conveniences. It is a drop-in replacement for the
everyday `ls` invocations: the same flags (`-l`, `-a`, `-A`, `-1`, `-h`, `-t`,
`-S`, `-r`) do the same things, and the output adds file-type colors, Nerd Font
icons, human-readable sizes, and permission and date columns that line up.

Beyond `ls` it adds a recursive `--tree` view with a configurable `--depth`,
glob-based filtering with `--ignore-glob`, configurable column order via
`--blocks`, git status integration with `--git`, and full theming through a
YAML config file. `--classic` turns all of it off and gives you plain `ls`-like
output, and `--color`/`--icon` take `always`/`auto`/`never` so scripts get
deterministic text.

## What's included

- **lsd** — the listing binary. Run `lsd` in place of `ls`, `lsd -l` for the
  long table, `lsd --tree` to recurse, or `lsd --classic --color never` for
  plain, script-friendly output.

The mirrored archives also carry upstream's `lsd.1` man page and shell
completions for bash, zsh, fish and PowerShell alongside the binary.

## Install with ocx

```sh
ocx install ocx.sh/lsd-rs/lsd
```

```sh
# or pin a specific version
ocx install ocx.sh/lsd-rs/lsd:1.2.0
```
