# regbot

regbot is the registry automation bot from the [regclient](https://github.com/regclient/regclient)
project. Where [regsync](https://github.com/regclient/regclient/blob/main/docs/regsync.md)
copies images by a declarative config, regbot runs **scripts** — each entry in
its config is a Lua program with the regclient API bound into it, so retention
and maintenance policies that a config file cannot express are written directly:
delete tags older than N days, keep the newest N builds per branch, retag on a
condition, mirror only what matches a rule.

Run it once (`regbot once`) from CI or cron, or leave it running as a server
with per-script schedules. Every script can be rehearsed with `--dry-run`, which
executes the policy logic but skips every external action.

## What's included

- **regbot** — the automation bot (`once`, `server`, `version`)

## Typical uses

```sh
regbot once --dry-run -c regbot.yml   # rehearse the policy, change nothing
regbot once -c regbot.yml             # apply it
regbot server -c regbot.yml           # run on the config's schedules
```
