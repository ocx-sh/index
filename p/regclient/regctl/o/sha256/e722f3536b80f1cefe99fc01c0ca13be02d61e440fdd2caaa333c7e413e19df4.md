# regctl

regctl is the registry client CLI from the [regclient](https://github.com/regclient/regclient)
project. It inspects, copies and manipulates images in OCI/Docker registries by
talking the registry API directly — no Docker daemon, no local image store, and
no pull of layers it does not need. Copying an image between registries moves
only the blobs the target is missing, and multi-platform indexes, referrers and
annotations survive the round trip intact.

It also reads and writes a local `ocidir://` OCI layout, so images can be built
up, retagged and inspected entirely offline.

## What's included

- **regctl** — the registry CLI

Command groups: `artifact`, `blob`, `image`, `index`, `manifest`, `registry`,
`repo`, `tag`, plus `config`, `completion` and `version`.

## Typical uses

```sh
regctl image copy ghcr.io/regclient/regctl:latest registry.example.org/regctl:latest
regctl manifest get alpine:latest --platform linux/arm64
regctl image ratelimit alpine
regctl index create ocidir://local:v1
```
