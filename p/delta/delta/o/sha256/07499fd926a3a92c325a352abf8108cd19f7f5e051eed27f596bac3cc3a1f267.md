# delta

[delta](https://dandavison.github.io/delta/) is a viewer for unified diffs. It
reads `git diff`, `git show`, `git log -p`, `git blame`, `diff -u` or `grep`
output on stdin and re-renders it with language-aware syntax highlighting,
within-line change highlighting, side-by-side layout, line numbers and
navigable file/hunk headers.

Wire it in as git's pager (`core.pager = delta`, `interactive.diffFilter =
delta --color-only`) and every diff git already prints comes out highlighted —
no change to how you use git. It also works standalone: pipe any unified diff
into it, or hand it two files to compare.

## What's included

- **delta** — the diff viewer. Feed it a unified diff on stdin, or run
  `delta OLD NEW` to compare two files. `-s`/`--side-by-side` splits the view
  into two columns, `-n`/`--line-numbers` adds the line-number gutter,
  `--color-only` colors the diff without altering its structure (the mode git's
  `interactive.diffFilter` wants), and `--no-gitconfig` ignores any delta
  configuration in your git config.

The project is `delta` and the executable is `delta`; only the Rust crate is
published as `git-delta`, because `delta` was taken on crates.io.
