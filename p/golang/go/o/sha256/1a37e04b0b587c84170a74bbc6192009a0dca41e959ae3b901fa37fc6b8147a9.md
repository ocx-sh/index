# Go

Go is an open-source programming language designed at Google for building
simple, reliable, and efficient software. The distribution ships the compiler,
the `go` command (build system, module manager, test runner), the full
standard library, and the canonical source formatter.

## What's included

- **go** — the Go toolchain front end: `go build`, `go run`, `go test`,
  `go mod`, and the bundled compiler, linker, and standard library
- **gofmt** — the canonical Go source formatter
