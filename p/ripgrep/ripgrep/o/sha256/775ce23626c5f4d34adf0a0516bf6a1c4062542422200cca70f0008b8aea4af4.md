# ripgrep

[ripgrep](https://github.com/BurntSushi/ripgrep) (`rg`) is a line-oriented
search tool that recursively searches the current directory for a regular
expression pattern. It is built on Rust's `regex` crate — finite automata, SIMD
and aggressive literal optimisations — and by default skips files ignored by
`.gitignore`, hidden files and binary files, which is what makes a whole-tree
search feel instant.

Unicode support is on by default: `\w`, `\b` and case-insensitive matching all
follow Unicode rules rather than ASCII ones. Search can be scoped by file type
(`--type rust`), by glob (`--glob '*.md'`), or widened to everything with
`--no-ignore --hidden --binary`.

## What's included

- **rg** — the search binary. `rg <pattern>` searches the tree below the
  current directory; `rg <pattern> <path>` scopes it. `--count-matches`,
  `--only-matching`, `--replace`, `--json` and `--files` cover counting,
  extraction, substitution preview and plain file listing.

The archive also ships the `rg.1` man page under `doc/` and shell completions
for bash, zsh, fish and PowerShell under `complete/` — both are inside the
bundle but neither is wired onto `PATH` or `MANPATH`.
