# kubectl

kubectl is the Kubernetes command-line tool. It lets you deploy applications,
inspect and manage cluster resources, view logs, and drive every Kubernetes
API operation from the terminal.

## What's included

- **kubectl** — the Kubernetes CLI: `apply`, `get`, `describe`, `logs`,
  `exec`, `rollout`, and the full API surface, including the built-in
  kustomize integration
