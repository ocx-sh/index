# caddy

Caddy is a web server and reverse proxy that obtains and renews TLS
certificates automatically. A site is served over HTTPS from the first request
with no certificate management, no cron job and no ACME client to wire up —
`caddy` talks to Let's Encrypt (or ZeroSSL) itself, keeps the certificates
current, and falls back to a locally-trusted internal CA for development
domains.

Configuration is JSON natively, but the built-in Caddyfile adapter accepts a
short, declarative syntax that reads like the site it describes. A running
instance is reconfigured over a local admin API with zero downtime, so a config
change never drops a connection. The same binary is also a
production-ready static file server (`caddy file-server`), a reverse proxy
(`caddy reverse-proxy`) and a canned HTTP responder (`caddy respond`) straight
from the command line.

Caddy speaks HTTP/1.1, HTTP/2 and HTTP/3, and everything ships in one
dependency-free static executable — no libc requirement, no runtime, no
modules to install for the standard distribution.
