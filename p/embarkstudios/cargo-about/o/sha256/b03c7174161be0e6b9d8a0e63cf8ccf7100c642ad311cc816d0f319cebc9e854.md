# cargo-about

cargo-about is a cargo plugin from [Embark Studios](https://github.com/EmbarkStudios)
that answers the question every shipped Rust binary eventually has to answer:
*whose code is in here, and under what terms?* It walks the crate graph,
resolves each crate's license, and renders the result through a Handlebars
template — so the attribution page you ship is generated from the lockfile
rather than maintained by hand.

Where its sibling [cargo-deny](https://index.ocx.sh/embarkstudios/cargo-deny)
*gates* on license policy, cargo-about *documents* it. The two are usually run
together: deny in CI to fail the build, about at release time to produce the
NOTICE.

Three subcommands:

- **generate** — render the license listing for a workspace through a
  Handlebars template (`about.hbs`), configured by `about.toml`.
- **init** — scaffold that `about.toml` and a starter template.
- **clarify** — compute a clarification entry for one license file: its detected
  SPDX id, the confidence score, and a sha256 of the exact bytes. Useful when a
  crate's license text is non-standard and needs pinning by hash.

## What's included

- **cargo-about** — the generator (`generate`, `init`, `clarify`). Runs
  standalone or as `cargo about …` once it is on `PATH`.

`cargo-about generate` and `cargo-about init` read the crate graph via
`cargo metadata`, so they need a Rust toolchain on `PATH` alongside this
package; `cargo-about clarify` and `cargo-about --version` do not.
