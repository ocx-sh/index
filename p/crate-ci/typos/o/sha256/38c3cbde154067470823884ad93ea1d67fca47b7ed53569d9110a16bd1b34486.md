# typos

[typos](https://github.com/crate-ci/typos) is a source-code spell checker. It
walks a tree, splits each file into identifiers and then into words, and reports
only the words it can correct with high confidence — so `recieve` is flagged and
`fn recv` is not. The dictionary is compiled into the binary, which makes a run
hermetic and fast enough to sit in a pre-commit hook.

Corrections are conservative by construction: the dictionary is built from
`typos-dict`, `codespell-dict`, `misspell-dict` and Wikipedia's list of common
misspellings, and entries that are ambiguous in real code are excluded rather
than guessed. Identifier splitting understands `snake_case`, `camelCase`,
`SCREAMING_CASE` and hex/base64-looking runs, so it does not shout at data.

`--write-changes` applies the corrections in place and `--diff` prints what it
would do. `--format json` (or `sarif`) turns the result into machine-readable
jsonlines for a CI report. Behaviour is tuned by a `.typos.toml` /
`_typos.toml` / `pyproject.toml` config — per-file, per-extension and
per-identifier allow-lists — or pinned off entirely with `--isolated`.

**Exit codes are inverted relative to most linters and are part of the
contract:** `0` when nothing was found, `2` when typos were found, anything else
is a real error.

## What's included

- **typos** — the checker. `typos` checks the current directory; `typos PATH…`
  checks explicit paths and `-` reads stdin. `--write-changes` fixes in place,
  `--diff` previews, `--format json|sarif|brief|long|silent` selects the report,
  `--locale en-us|en-gb|en-ca|en-au` picks the correction dialect, and
  `--exclude GLOB` / `.typos.toml` narrow the walk.

The release archive also ships upstream's `LICENSE-APACHE`, `LICENSE-MIT`,
`README.md` and a `doc/` directory beside the binary; they are inside the bundle
but not on `PATH`.
