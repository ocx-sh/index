# mdbook

[mdBook](https://github.com/rust-lang/mdBook) turns a directory of Markdown
files into a searchable, navigable online book. It is the tool behind *The Rust
Programming Language*, the Rust Reference and most of the rust-lang
documentation, and it works just as well for any project's handbook, API guide
or internal runbook.

A book is a `book.toml` plus a `src/` directory whose `SUMMARY.md` lists the
chapters in order. `mdbook build` renders that into a self-contained `book/`
directory of static HTML — no server, no build pipeline, no JavaScript
toolchain — with a sidebar table of contents, light/dark/ayu themes, syntax
highlighting, a client-side full-text search index, print-to-PDF output and
permalinked headings. `mdbook serve` adds a local preview server that rebuilds
and live-reloads as you type, and `mdbook watch` rebuilds without serving.

Rust code samples in a book are executable documentation: `mdbook test` runs
them through `rustdoc` so a snippet that stops compiling fails the build rather
than quietly rotting. (That verb needs a Rust toolchain on the host — it is not
part of this package.) Books are extensible through *preprocessors*, which
rewrite the Markdown before rendering, and *alternative backends*, which render
the parsed book to something other than HTML; both are ordinary executables
discovered on `PATH`, so no plugin needs to be compiled into mdBook itself.

## What's included

- **mdbook** — the whole tool, one static binary with the HTML front-end
  compiled in. `mdbook init` scaffolds a book, `mdbook build` renders it,
  `mdbook serve` previews it with live reload, `mdbook watch` rebuilds on
  change, `mdbook clean` removes the output, and `mdbook completions <shell>`
  writes shell completions to stdout.
