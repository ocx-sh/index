# uutils coreutils

[uutils coreutils](https://uutils.org) is a cross-platform rewrite of the GNU
coreutils in Rust. All utilities are compiled into one multicall binary,
`coreutils`, so the same commands behave the same on Linux, macOS and Windows.

## What's included

- **coreutils** — the multicall binary. Invoke a utility by name as the first
  argument: `coreutils ls -l`, `coreutils sort -u names.txt`,
  `coreutils sha256sum release.tar.gz`. `coreutils --list` prints every
  available utility.

## Per-utility names are deliberately not on PATH

Only `coreutils` is exposed. The individual names (`ls`, `cat`, `sort`, …) are
**not** put on `PATH`, because they would shadow the host's own tools for
everything that runs in the same environment. Call them through `coreutils`,
or alias them yourself where you want that.

## Platforms

Linux (amd64, arm64; static builds that run on glibc and musl), macOS (amd64,
arm64) and Windows arm64. Windows amd64 is not mirrored: upstream's x86_64
Windows archive ships ~85 standalone per-utility executables beside
`coreutils.exe`, which would all land on `PATH`.

The archive also ships upstream's `LICENSE` and `README.md`.
