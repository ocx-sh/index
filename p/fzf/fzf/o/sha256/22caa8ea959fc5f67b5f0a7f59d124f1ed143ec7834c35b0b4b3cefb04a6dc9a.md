# fzf

[fzf](https://junegunn.github.io/fzf/) is a general-purpose command-line fuzzy
finder and interactive terminal toolkit. Pipe it any list — files, git
branches, processes, command history — and it narrows the candidates as you
type, using fuzzy subsequence matching rather than exact substrings. It also
runs non-interactively: `fzf --filter <query>` behaves as a fuzzy `grep`, and
`--no-sort` keeps the input order.

Beyond plain filtering it supports preview windows, multi-select, custom key
bindings, and shell integration for `Ctrl-T` / `Ctrl-R` / `**<Tab>` completion
in bash, zsh and fish.

## What's included

- **fzf** — the fuzzy finder binary. Run it with a list on stdin to filter
  interactively, or `fzf --filter <query>` for a non-interactive fuzzy grep.

The shell-integration scripts and Vim plugin that live in the upstream Git
repository are not part of an upstream release archive, so they are not
mirrored — the release archives contain the `fzf` executable alone.

## Install with ocx

```sh
ocx install ocx.sh/fzf/fzf
```

```sh
# or pin a specific version
ocx install ocx.sh/fzf/fzf:0.74.2
```
