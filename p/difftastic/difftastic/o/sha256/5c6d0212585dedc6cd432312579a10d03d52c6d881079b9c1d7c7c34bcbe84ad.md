# difftastic

[difftastic](https://difftastic.wilfred.me.uk/) is a structural diff tool. It
parses both sides of a comparison with tree-sitter and diffs the resulting
syntax trees, so it reports what actually *changed* rather than which lines
moved. Reindenting a block, rewrapping an expression or reflowing a list is not
a change to difftastic; renaming a variable inside one of them is. It supports
50+ languages out of the box and falls back to a word-level text diff for
anything it cannot parse.

It reads as a drop-in `git diff` replacement — set it as `diff.external` or run
`GIT_EXTERNAL_DIFF=difft git diff` — and works the same way from Mercurial,
Jujutsu and Fossil.

## What's included

- **difft** — the structural diff binary. Run `difft OLD NEW` to compare two
  files or directories. `--display inline` swaps the default side-by-side view
  for a single column, `--exit-code` reports syntactic changes through the exit
  status, and `--syntax-highlight off` drops the colouring.

Note the executable is `difft`, not `difftastic`.
