# age

[age](https://age-encryption.org) is a simple, modern and secure file
encryption tool. It has small explicit keys, no config options, and
UNIX-style composability — encryption is a pipe, not a keyring.

Recipients are 62-character bech32 public keys (`age1…`) produced by
`age-keygen`, or an existing SSH public key (`ssh-ed25519 …`, `ssh-rsa …`), so
a file can be encrypted to a GitHub user's published SSH key without any prior
key exchange. Under the hood: X25519 key agreement, HKDF-SHA-256, and
ChaCha20-Poly1305 over a chunked STREAM construction — no negotiation, no
algorithm agility, no crypto config to get wrong.

The file format is specified at
[age-encryption.org/v1](https://age-encryption.org/v1) and implemented by
several independent tools, so a file encrypted here is not tied to this
binary.

## What's included

- **age** — the encryption tool. `age -r age1… -o out.age in.txt` encrypts;
  `age -d -i key.txt -o in.txt out.age` decrypts. `--armor` emits PEM text
  instead of binary, `-R` reads recipients from a file, and `-j <plugin>`
  routes to an installed `age-plugin-*`.
- **age-keygen** — generates an X25519 identity, printing the secret key on
  stdout and the public key on stderr. `age-keygen -y key.txt` re-derives the
  public key from an existing identity file.
- **age-inspect** — reports what an age file is without decrypting it: format
  version, armoring, recipient stanza types, and a size breakdown. `--json`
  gives machine-readable output.
- **age-plugin-batchpass** — an age plugin for non-interactive passphrase
  encryption driven by `AGE_PASSPHRASE` / `AGE_PASSPHRASE_FD`, for scripted
  and CI use where no terminal is available to prompt.
