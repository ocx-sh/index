# ruff

[ruff](https://github.com/astral-sh/ruff) is Astral's Python linter and code
formatter — a single static binary, 10–100× faster than the tools it replaces.
It reimplements over 800 lint rules from Flake8 and its plugin ecosystem,
isort, pyupgrade, pydocstyle and Pylint, plus a Black-compatible formatter,
behind one command and one configuration file.

## What's included

- **ruff** — the linter (`ruff check`) and formatter (`ruff format`)

## Platforms

Both Linux libc families are published as their own platform entries: a
glibc-linked build (`+libc.glibc`) and a fully static musl build
(`+libc.musl`), on amd64 and arm64 alike. macOS and Windows ship on both
Intel/AMD and ARM.

## Versions

Upstream tags bare semver (`0.16.1`); pre-1.0 minor bumps can change default
rule selection and formatter output, so pin the minor. Rolling `0.16`, `0` and
`latest` aliases track the newest published release.
