# ty

[ty](https://github.com/astral-sh/ty) is Astral's Python type checker and
language server — a single static binary built on the same infrastructure as
ruff. It performs whole-project type inference and gradual-typing checks
substantially faster than existing checkers, and ships an LSP server for
editor integration.

## What's included

- **ty** — the type checker (`ty check`) and language server (`ty server`)

## Platforms

Both Linux libc families are published as their own platform entries: a
glibc-linked build (`+libc.glibc`) and a fully static musl build
(`+libc.musl`), on amd64 and arm64 alike. macOS and Windows ship on both
Intel/AMD and ARM.

## Versions

ty is **pre-release software** on a `0.0.x` line: behaviour, diagnostics and
CLI surface can change between patch releases, and code that checks clean
today may not on the next version. Pin an exact version. Rolling `0.0`, `0`
and `latest` aliases track the newest published release. Upstream's
`-alpha.N` prereleases are not mirrored.
