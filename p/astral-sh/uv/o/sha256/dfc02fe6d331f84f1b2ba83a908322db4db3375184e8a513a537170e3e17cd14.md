# uv

[uv](https://github.com/astral-sh/uv) is Astral's Python package and project
manager — a single static binary that replaces `pip`, `pip-tools`, `pipx`,
`poetry`, `pyenv`, `virtualenv` and `twine`. It resolves and installs
dependencies 10–100× faster than `pip`, with a universal lockfile, workspace
support, and its own Python-version management.

## What's included

- **uv** — the package and project manager
- **uvx** — the ephemeral tool runner (equivalent to `uv tool run`)
- **uvw** — Windows only: the same launcher without a console window

## Platforms

Both Linux libc families are published as their own platform entries: a
glibc-linked build (`+libc.glibc`) and a fully static musl build
(`+libc.musl`), on amd64 and arm64 alike. macOS and Windows ship on both
Intel/AMD and ARM.

## Versions

Upstream tags bare semver (`0.12.1`); pre-1.0 minor bumps can carry breaking
changes, so pin the minor. Rolling `0.12`, `0` and `latest` aliases track the
newest published release.
