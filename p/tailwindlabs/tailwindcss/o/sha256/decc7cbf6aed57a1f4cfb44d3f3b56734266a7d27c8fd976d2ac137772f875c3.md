# Tailwind CSS

Tailwind CSS is a utility-first CSS framework: instead of writing stylesheets,
you compose designs from small single-purpose classes applied directly in
markup, and the compiler emits only the CSS those classes actually need.

This package mirrors the **standalone CLI** — a single self-contained
executable that carries the whole Tailwind toolchain (the framework CSS, the
class scanner and the code generator) with no Node.js, npm or `node_modules`
anywhere in the picture.

## What's included

- **tailwindcss** — compiles a stylesheet: `tailwindcss -i input.css -o output.css`,
  with `--watch` for incremental rebuilds and `--minify` for production output.
  Sources to scan are declared in the CSS itself via `@source`.

## Notes

The Linux builds are dynamically linked, and the two flavours are published as
separate platform entries — the glibc build resolves on a glibc host, the musl
build on a musl one. The **musl build additionally needs `libstdc++`**, which
minimal musl images such as `alpine` do not install by default
(`apk add libstdc++`). The glibc build needs nothing beyond glibc 2.17.
