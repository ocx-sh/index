# sops

[sops](https://github.com/getsops/sops) (Secrets OPerationS) is a CNCF project
for keeping encrypted secrets **in** your repository. It encrypts the *values*
of a YAML, JSON, ENV, INI or binary document and leaves the *keys* in plain
text, so an encrypted file still diffs, reviews and merges like the structured
document it is. Data keys are wrapped by one or more master keys — AWS KMS, GCP
KMS, HuaweiCloud KMS, Azure Key Vault, HashiCorp Vault Transit, `age` or PGP —
and a document can carry several at once, so rotating or revoking one operator
does not re-encrypt the payload.

## What's included

- **sops** — the binary. `sops encrypt` / `sops decrypt` stream a document
  through the configured master keys, `sops edit` opens the decrypted form in
  `$EDITOR` and re-encrypts on save, `sops filestatus` answers whether a file is
  encrypted, `sops rotate` issues a fresh data key, `sops updatekeys` applies
  the creation rules in `.sops.yaml`, and `sops exec-env` / `sops exec-file`
  hand the decrypted values to a child process without ever writing them to
  disk.

## Quick start

```sh
# age needs no cloud account and no key server
age-keygen -o key.txt
export SOPS_AGE_KEY_FILE=key.txt

sops encrypt --age "$(grep -o 'age1.*' key.txt)" secrets.yaml > secrets.enc.yaml
sops decrypt secrets.enc.yaml
```

```yaml
# .sops.yaml — creation rules, so the flags are needed only once
creation_rules:
  - path_regex: \.enc\.yaml$
    age: age1pnexrx2thvq8h8dm8aa996cx87kq2th6pcvwc2323arrxp7hr3rsc6j803
```

```sh
sops exec-env secrets.enc.yaml 'printenv DATABASE_URL'
```
