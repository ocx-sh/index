# deno

Deno is a runtime for JavaScript and TypeScript built on V8 and Rust. It runs
TypeScript directly — no separate compile step, no build config — and is secure
by default: a program gets no file, network, or environment access until it is
granted explicitly. Modules resolve from URLs, JSR and npm, and lock to a
checksummed `deno.lock`.

The single `deno` executable also carries the toolchain that would otherwise be
a handful of separate dependencies: a formatter (`deno fmt`), a linter
(`deno lint`), a test runner with coverage (`deno test`), a type checker
(`deno check`), a language server (`deno lsp`), a benchmark runner
(`deno bench`), a REPL, and `deno compile`, which produces a self-contained
executable. No runtime dependencies beyond the host's C library.

## What's included

- **deno** — the Deno runtime and toolchain CLI
