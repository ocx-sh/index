# hexyl

hexyl is a hex viewer for the terminal. It renders a file — or standard input —
as a bordered dump with a position gutter, one or more hex panels and a
character panel, and colors each byte by category: NULL bytes, ASCII
whitespace, printable ASCII and non-ASCII each get their own color, so the
shape of a binary is readable at a glance. Output is configurable rather than
fixed: choose the base (hexadecimal, decimal, octal, binary), the group size
and endianness, the number of panels, the character table and the border style,
or drop all of it with `--plain`. `--skip` and `--length` window into a region
of the input, and `--display-offset` renumbers the positions.

## What's included

- **hexyl** — the hex viewer CLI, plus the `hexyl.1` man page. Shell
  completions are generated on demand with `hexyl --completion <shell>` for
  bash, zsh, fish, elvish and PowerShell.
