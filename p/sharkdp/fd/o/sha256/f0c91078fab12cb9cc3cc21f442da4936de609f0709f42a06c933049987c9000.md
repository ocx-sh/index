# fd

fd is a fast alternative to `find` with defaults chosen for the common case: a
bare pattern is matched as a regular expression against file *names*, the search
is recursive from the current directory, results are colorized by file type, and
hidden files plus anything listed in `.gitignore` are skipped unless asked for.
It walks directories in parallel, supports glob matching, filtering by type,
extension, size and modification time, and can execute a command per result — or
batched across all results — with `--exec` and `--exec-batch`.

## What's included

- **fd** — the search CLI, with bundled shell-completion scripts for bash, zsh,
  fish and PowerShell, and the `fd.1` man page.
