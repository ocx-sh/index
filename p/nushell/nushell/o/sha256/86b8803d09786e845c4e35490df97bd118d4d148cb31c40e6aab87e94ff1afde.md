# Nushell

Nushell (`nu`) is a modern shell that models the command pipeline as
structured data rather than raw text. Commands pass typed tables, records,
and lists between one another, so filtering, sorting, and transforming
output works the same way across files, system info, and external tools.
It runs on Linux, macOS, and Windows and ships with a batteries-included
set of built-in commands and plugins.

## What's included

- **nu** — the Nushell shell and scripting language interpreter
- **nu_plugin_*** — bundled plugins (`polars`, `formats`, `query`, `gstat`,
  `inc`, and more) registered into Nushell with `plugin add`
