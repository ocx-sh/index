# geckodriver

geckodriver is Mozilla's implementation of the [W3C WebDriver][w3c] protocol
for Firefox. It runs as an HTTP server that translates WebDriver commands into
the Marionette protocol Firefox speaks internally, so any WebDriver client —
Selenium, WebdriverIO, Playwright's Firefox channel, or a plain HTTP client —
can create sessions, navigate, interact with the DOM and capture screenshots
against a real Firefox.

It is a self-contained binary. Firefox itself is not bundled and is not
supplied by this package: point geckodriver at an installed browser with
`--binary`, or let it discover one on `PATH`.

## What's included

- **geckodriver** — the WebDriver server (`--port`, `--host`, `--binary`, `--log <fatal|error|warn|info|config|debug|trace>`, `--allow-hosts`, `--allow-origins`, …)
