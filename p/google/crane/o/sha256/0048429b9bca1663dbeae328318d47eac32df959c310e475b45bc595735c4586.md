# crane

crane is a command-line registry client from Google's
[go-containerregistry](https://github.com/google/go-containerregistry) project.
It reads and writes container images directly against a registry — no Docker
daemon, no local image store, no privileged socket — which makes it the tool of
choice for CI jobs that need to copy, retag, inspect or rebase images without
first pulling them into a runtime.

Typical uses: `crane copy` an image between registries while preserving its
digest, `crane digest` to pin a tag, `crane ls` to enumerate tags,
`crane manifest` / `crane config` to read metadata, `crane append` to add a
layer, and `crane rebase` to swap an image's base out from under it.

## What's included

- **crane** — the registry client (`copy`, `pull`, `push`, `ls`, `digest`,
  `manifest`, `config`, `append`, `rebase`, `mutate`, `export`, `validate`,
  `index`, `registry serve`).
- **gcrane** — crane plus Google Container Registry extras (`gc`, recursive
  `ls`, `copy` of an entire repository).
- **krane** — crane built with Kubernetes-style credential helpers linked in,
  for clusters whose registry auth comes from a cloud provider.

All three are single static binaries with no runtime dependencies, and all
three ship in every upstream archive, so all three land on `PATH`.
