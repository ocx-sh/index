# otelcol

The [OpenTelemetry Collector](https://opentelemetry.io/docs/collector/) is a
vendor-neutral process that receives telemetry (traces, metrics and logs),
processes it, and exports it to one or more backends. You describe the
receivers, processors, exporters and the pipelines that join them in a YAML
file, and the collector runs that graph.

This package is the **core distribution** (`otelcol`). It contains every
component from the collector's core repository — OTLP receivers and exporters,
the `batch` and `memory_limiter` processors, the `debug` exporter, and so on —
plus a small selection of components from the contrib repository (for
example `file_log` and `host_metrics`). It is deliberately small.

It is **not** the contrib distribution. `otelcol-contrib`, `otelcol-k8s`,
`otelcol-otlp`, `otelcol-prometheus` and `otelcol-ebpf-profiler` are separate
builds with different component sets and are not part of this package. List
exactly what this build contains with `otelcol components`.

## What's included

- `otelcol` — the collector (`otelcol.exe` on Windows)

## Usage

```sh
# check a configuration without starting the collector
otelcol validate --config=config.yaml
```

```sh
# run the collector with a configuration
otelcol --config=config.yaml
```

```sh
# list the receivers, processors, exporters, extensions and connectors built in
otelcol components
```

```sh
# print the effective configuration after merging all sources
otelcol print-config --config=config.yaml
```

`--config` may be repeated to merge several files, and `--set` overrides a
single property from the command line.
