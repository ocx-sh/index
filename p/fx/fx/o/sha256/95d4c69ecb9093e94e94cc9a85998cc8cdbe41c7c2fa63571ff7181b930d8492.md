# fx

[fx](https://github.com/antonmedv/fx) is a terminal JSON viewer and processor.
It has two modes and they behave quite differently:

- **Interactive.** `fx data.json` opens a full-screen viewer with folding,
  search, vim-style motions and themes, for exploring a document you do not yet
  understand.
- **Non-interactive.** `cat data.json | fx '<expression>'` streams the document
  through a JavaScript expression and prints the result. This is the mode that
  composes into pipelines, and the one the smoke test exercises.

The expression language is **JavaScript**, not a bespoke query dialect: an
expression starts at `.` for the root document and everything after it is
ordinary JS, so `.items.filter(x => x.active).map(x => x.id)` works with no
syntax to learn beyond the leading dot. Input can also be parsed as YAML
(`--yaml`) or TOML (`--toml`), and `--slurp` folds a stream of documents into a
single array.

## What's included

- **fx** — the viewer and processor. `fx <file>` opens the interactive viewer;
  `… | fx '<expr>'` evaluates an expression against piped input and prints the
  result. `-r/--raw` treats input as a raw string, `-s/--slurp` reads all
  inputs into an array, `--yaml`/`--toml` switch the input parser, and
  `--strict` rejects non-standard JSON.

Note that **piped input with no expression is not a supported combination** —
fx tries to open the terminal for its viewer and fails. Pass an expression when
stdin is a pipe.

## Install with ocx

```sh
ocx install ocx.sh/fx/fx
```

```sh
# or pin a specific version
ocx install ocx.sh/fx/fx:39.2.0
```
