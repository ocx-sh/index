# fnox

fnox is a flexible secret management tool by @jdx. It stores secrets encrypted at rest, resolves them from local and remote providers, and injects them into your shell environment or a single command's environment on demand. It supports profiles, ephemeral credential leases, shell activation, and an MCP server for secret-gated AI agent access.

## What's included

- **fnox** — the secret-management CLI (`exec`, `get`, `list`, `export`, `lease`, `activate`, `mcp`, …)
