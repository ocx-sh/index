# actionlint

actionlint is a static checker for GitHub Actions workflow files. It checks
workflow syntax against the official schema, validates `${{ }}` expressions and
their contexts, detects unavailable runner labels and typos, and runs
[shellcheck](https://www.shellcheck.net/) on `run:` scripts and
[pyflakes](https://pypi.org/project/pyflakes/) on inline Python when those tools
are present. A single self-contained binary, no runtime dependencies.

## What's included

- **actionlint** — the workflow linter CLI
