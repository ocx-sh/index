# dust

[dust](https://github.com/bootandy/dust) is `du` + Rust: a more intuitive way
to see where your disk space has gone. Point it at a directory and it walks the
tree in parallel, then prints the biggest entries as an indented tree with
percentage bars, so a single screen tells you both *which* directory is large
and *how concentrated* that size is inside it.

Unlike `du`, it needs no `| sort -h | tail`, no `--max-depth` guessing and no
mental unit conversion — the output is already ranked, already scaled to the
terminal, and already scoped to the entries worth looking at.

## What's included

- **dust** — the disk-usage binary. Run `dust` for the current directory or
  `dust <path>...` for specific ones. Useful flags: `-n <N>` to cap the number
  of entries, `-d <N>` to limit depth, `-F` for files only (find your largest
  files), `-e/-v <regex>` to filter paths in or out, `-s` for apparent size
  instead of allocated blocks, `-o <unit>` to fix the size unit, `-r` to print
  biggest-first, and `-R` for a plain screen-reader-friendly table.

## Install with ocx

```sh
ocx install ocx.sh/dust/dust
```

```sh
# or pin a specific version
ocx install ocx.sh/dust/dust:1.2.4
```
