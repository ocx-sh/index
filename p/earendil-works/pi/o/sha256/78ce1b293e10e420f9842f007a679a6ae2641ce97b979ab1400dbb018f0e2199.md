# pi

[pi](https://pi.dev) is a terminal coding agent from
[Earendil Works](https://earendil.com). It drives an LLM of your choice with a
small set of tools — `read`, `bash`, `edit`, `write` — in an interactive TUI or
non-interactively (`pi -p "…"`), and keeps every conversation as a session file
you can continue, fork or export.

## What's included

- **pi** — the CLI, shipped as a self-contained binary with its bundled
  themes, HTML-export template and docs beside it.

## Highlights

- **Any provider** — Anthropic, OpenAI, Google, local llama.cpp and more;
  `pi --list-models` shows what is configured, `pi auth` manages logins.
- **Sessions** — `pi -c` continues the last session for the current directory,
  `pi -r` picks one, `pi --export <session> [out.html]` renders it to HTML.
- **Extensible** — skills, prompt templates, themes, extensions
  (`pi install <source>`) and MCP servers (`pi mcp`).
- **Scriptable** — `--mode json` and `--mode rpc` for integration.

## Configuration

Credentials come from provider environment variables (e.g. `ANTHROPIC_API_KEY`)
or `pi auth login`. Settings and sessions live under `~/.pi/`. `--offline`
(or `PI_OFFLINE=1`) disables startup network operations.

## Platforms

Linux (amd64, arm64; glibc), macOS (amd64, arm64) and Windows (amd64, arm64).
