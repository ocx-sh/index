# starship

[starship](https://starship.rs) is a cross-shell prompt: a single binary that
renders your shell prompt from the state of the current directory. It detects
the git branch and working-tree status, the active language toolchain and its
version (Rust, Node, Python, Go, Java and ~50 more), the cloud or Kubernetes
context, the command duration and exit status, and prints only the modules that
are actually relevant to where you are standing.

It is written in Rust and targets sub-millisecond rendering, so the prompt does
not lag behind the shell. Every module — its symbol, style, format string and
detection rules — is configurable from one `starship.toml`, and it drives
bash, zsh, fish, PowerShell, Ion, Nushell, Elvish, Tcsh, Xonsh and cmd from the
same configuration.

## What's included

- **starship** — the prompt binary. `starship init <shell>` prints the shell
  function that wires it into your rc file; `starship prompt` renders one
  prompt; `starship module <name>` renders a single module; `starship preset`
  prints a ready-made configuration.

The Nerd Font glyphs the default preset uses are not part of an upstream
release archive and are not mirrored — install a patched font, or use
`starship preset plain-text-symbols` for a font-independent prompt.

## Shell setup

Add the init line for your shell, e.g. for bash:

```sh
eval "$(starship init bash)"
```
