# Bazelisk

Bazelisk is the official Bazel version launcher from the Bazel team. It reads
your workspace's `.bazelversion` file (or the `USE_BAZEL_VERSION` environment
variable) and automatically downloads the specified Bazel release, caching it
locally. This guarantees that every developer and CI job uses the same Bazel
version without any manual installation.

Users typically invoke Bazelisk as `bazel` by symlinking or renaming the
binary — it is a transparent drop-in replacement for the `bazel` command.

## What's included

- **bazelisk** — the single static binary. No runtime dependencies.
  Reads `.bazelversion` or `USE_BAZEL_VERSION`, downloads the correct Bazel
  release on first use, and delegates to it.
