# zoxide

[zoxide](https://github.com/ajeetdsouza/zoxide) is a smarter `cd` command. It
remembers every directory you visit and ranks them by *frecency* — a blend of
how often and how recently you were there — so `z proj` takes you straight to
the project directory you actually meant, from anywhere. It is a rewrite of
`autojump`/`z` in Rust, and it works with bash, zsh, fish, nushell, elvish,
PowerShell, xonsh and more.

## What's included

- **zoxide** — the binary. `zoxide add <dir>` records a directory, `zoxide
  query <keyword>` resolves a keyword back to a full path, and
  `zoxide init <shell>` emits the shell snippet that installs the interactive
  `z` and `zi` commands.

The archive also ships man pages and shell completions for every supported
shell alongside the binary.

## Shell integration

zoxide is only useful once its shell hook is installed — add the appropriate
line to your shell's config file:

```sh
# bash — ~/.bashrc
eval "$(zoxide init bash)"
```

```sh
# zsh — ~/.zshrc
eval "$(zoxide init zsh)"
```

```sh
# fish — ~/.config/fish/config.fish
zoxide init fish | source
```

Then `z <keyword>` jumps, and `zi <keyword>` picks interactively.
