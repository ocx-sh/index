# kustomize

kustomize customizes raw, template-free Kubernetes YAML. Instead of
parameterising manifests with placeholders, it keeps a plain, valid base and
layers declarative *overlays* on top of it — so the base stays deployable on
its own and each environment is described by what it changes rather than by a
values file.

`kustomize build` renders a directory to stdout: it accumulates resources,
applies strategic-merge and JSON patches, injects name prefixes/suffixes,
labels, annotations and namespaces, rewrites image tags, and generates
ConfigMaps and Secrets whose names carry a hash of their content — so a change
to configuration rolls the pods that consume it.

The same engine is built into `kubectl` as `kubectl kustomize` / `apply -k`,
but that copy lags upstream; this standalone binary is the current one, and it
is what CI pipelines and GitOps controllers pin.

## What's included

- **kustomize** — the CLI (`build`, `create`, `edit`, `cfg`, `fn`,
  `localize`, `version`).
