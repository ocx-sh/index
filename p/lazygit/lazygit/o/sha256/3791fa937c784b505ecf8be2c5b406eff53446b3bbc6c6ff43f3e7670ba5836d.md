# lazygit

[lazygit](https://github.com/jesseduffield/lazygit) is a terminal UI for git.
It puts status, branches, commits, stash and the diff view on one screen and
drives them from single keystrokes: stage individual lines or hunks, amend a
commit from earlier in the history, interactively rebase without writing a
todo file, resolve conflicts side by side, and undo it all with the reflog. It
is a single self-contained binary with no runtime to install.

## What's included

- **lazygit** — the binary. Run it inside any repository to open the UI, or
  use `lazygit -p <path>` to point it at another working tree. `lazygit
  --config` prints the default configuration to seed your own,
  `lazygit --print-config-dir` says where that file belongs, and
  `lazygit completion bash|zsh` emits a shell completion script.

## Requires git

lazygit is a front end, not a git implementation: **`git` must be installed and
on `PATH`**. This package ships lazygit only — it does not bundle git, and OCX
has no way to declare a runtime dependency on a tool the host provides. Every
platform this package targets ships git by default or one package-manager
command away; if `git` is missing, lazygit starts but every operation fails.

## Quick start

```sh
cd /path/to/repo
lazygit                  # open the UI on the status panel
lazygit log              # open focused on the commits panel
lazygit -f path/to/file  # filter the history to one path
```

Inside the UI: `?` lists the keybindings for the focused panel, `space` stages
the selected file (or hunk, in the staging view), `c` commits, `p` pulls,
`P` pushes, `z` undoes via the reflog, and `q` quits.

```sh
# seed a config file of your own
lazygit --config > "$(lazygit --print-config-dir)/config.yml"
```

## Install with ocx

```sh
ocx install ocx.sh/lazygit/lazygit
```

```sh
# or pin a specific version
ocx install ocx.sh/lazygit/lazygit:0.63.1
```
