# watchexec

[watchexec](https://github.com/watchexec/watchexec) runs a command whenever
files change. It monitors a directory tree with the kernel's native watch
mechanism (inotify on Linux, FSEvents on macOS, ReadDirectoryChangesW on
Windows), debounces the resulting event storm, and re-runs the command you gave
it — the generic form of `cargo watch`, `nodemon`, `entr` and every ad-hoc
`while sleep 1` loop, with no language or build system baked in.

Events are filtered before they reach your command: `-e/--exts` limits to file
extensions, `-f/--filter` takes glob patterns, `--ignore-file` reads
`.gitignore`-style files (and VCS ignores are honoured by default), and
`-j/--filter-prog` takes a full expression program for anything more involved.
`--fs-events` narrows by event kind, so a mirror or an editor's atomic-save
dance does not trigger a rebuild.

What happens to a still-running command when the next change arrives is
`--on-busy-update`: `queue` (finish, then run again), `restart` (signal, wait,
then re-run), `signal` (just signal it), or `do-nothing`. `-r` is the shorthand
for restart. Long-running processes are managed as a process group — a `pid1`
build is shipped so a server and every child it spawned go down together
instead of leaking — and `--stop-signal` / `--stop-timeout` control how firmly.

Handy extras: `-c/--clear` wipes the screen between runs, `-p/--postpone` skips
the run at startup and waits for the first change, `--stdin-quit` exits when
stdin closes (what process managers use to avoid zombies), `--emit-events-to`
passes the change list to the command as environment variables, stdin, or JSON,
and `-N/--notify` fires a desktop notification per run.

## What's included

- **watchexec** — the watcher binary. `watchexec make` re-runs make on any
  change; `watchexec -e rs,toml cargo test` narrows to Rust sources;
  `watchexec -r -- npm start` restarts a server on every edit;
  `watchexec -c -w src -- ./build.sh` clears the screen and watches one
  directory.

The mirrored archives also carry upstream's `watchexec.1` man page, its
Markdown source, the project logo and shell completions for bash, zsh, fish,
elvish, nushell and PowerShell alongside the binary.
