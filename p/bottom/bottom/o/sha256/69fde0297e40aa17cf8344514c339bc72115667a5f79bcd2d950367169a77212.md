# bottom

[bottom](https://github.com/ClementTsang/bottom) (`btm`) is a cross-platform
graphical process and system monitor for the terminal — CPU, memory, network,
disk, temperature, battery and process widgets drawn as live braille graphs in
a configurable grid, inspired by `gtop` and `gotop`.

The process widget is the working end: search with plain text or regex
(`-R`), group by name (`-g`), switch to a process tree (`-T`), sort by any
column, and — outside `--read_only` mode — signal or kill from the table.
Layout, colours, widget set and default sort are all driven by a TOML config
file; `btm --config_location <path>` writes a fully commented default one at
that path if it does not exist, which is the intended starting point.

Six built-in themes ship in the binary (`--theme default|default-light|gruvbox|
gruvbox-light|nord|nord-light`), and `--basic` collapses the graphs into an
htop-shaped text view for narrow terminals.

## What's included

- **btm** — the monitor. Run it bare for the default layout; `-b` for basic
  mode, `-e` to start with the default widget expanded, `--rate`/`--retention`
  to trade refresh frequency against resource use, `-C <path>` to point at (or
  generate) a config file.

The archive also ships shell completions for bash, zsh, fish, elvish, nushell,
PowerShell and TypeScript under `completion/` — inside the bundle, but not
wired onto `PATH`.

## Install with ocx

```sh
ocx install ocx.sh/bottom/bottom
```

```sh
# or pin a specific version
ocx install ocx.sh/bottom/bottom:0.14.7
```
