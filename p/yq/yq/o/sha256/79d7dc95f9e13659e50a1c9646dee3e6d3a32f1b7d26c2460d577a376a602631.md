# yq

yq is a portable command-line processor for YAML, JSON, XML, CSV, TOML, HCL and
properties documents by [@mikefarah](https://github.com/mikefarah). It reads,
queries, and transforms structured data with a jq-like expression syntax,
converts between formats, and edits files in place — all from a single static
binary with no runtime dependencies.

## What's included

- **yq** — the structured-data processor (`eval`, format conversion, in-place
  edits, merges, and jq-style path queries across YAML/JSON/XML/CSV/TOML/HCL).
