# glow

[glow](https://github.com/charmbracelet/glow) renders markdown in the
terminal. Point it at a file, a directory, a URL or a git forge path and it
prints the document styled — headings, lists, tables, code blocks, block quotes
— word-wrapped to your terminal. Run it bare and it opens a browser UI that
discovers every markdown file below the current directory (and in the enclosing
git repository) so you can read a project's docs without leaving the shell.

Built by [Charm](https://charm.sh) on
[Glamour](https://github.com/charmbracelet/glamour). Single static binary, no
runtime to install.

## What's included

- **glow** — the binary. `glow FILE.md` renders and exits; `glow` with no
  argument opens the TUI file browser; `glow -` reads markdown from stdin.
  Sources may also be a directory, an HTTP(S) URL, or a `github.com/owner/repo`
  style path, in which case glow fetches the README. `glow config` opens the
  config file in `$EDITOR`, and `glow completion bash|zsh|fish|powershell`
  emits a shell completion script.

## Quick start

```sh
glow README.md                 # render one file and exit
glow -w 80 CHANGELOG.md        # word-wrap at 80 columns
glow -s dark NOTES.md          # force a style: auto, dark, light, notty, or a JSON path
glow -p docs/guide.md          # page the rendered output
cat NOTES.md | glow -          # read from stdin

glow                           # TUI: browse every markdown file below here
glow github.com/charmbracelet/glow
```

Defaults live in a config file — `glow config` opens it, and `--config` points
at another one.

## Rendering vs. the TUI

glow has two modes and picks between them by what you give it. With a file,
directory or URL argument it renders to stdout and exits, which is the mode
that works in pipes, scripts and CI. With no argument it starts the
full-screen browser, which needs a terminal; `-t` forces it and `-p` sends the
rendered output through a pager. `-a` and `-l` affect the TUI only.

Styling follows the terminal: `-s auto` (the default) detects a light or dark
background, and `-s notty` produces plain unstyled text for redirection into a
file.
