# gum

[gum](https://github.com/charmbracelet/gum) turns the pieces of a terminal UI
into shell commands. Ask a question, offer a menu, fuzzy-filter a list, draw a
bordered box, show a spinner while something runs — each is one `gum` call that
writes its answer to stdout, so a plain `bash` script gets an interface without
a line of Go.

Built by [Charm](https://charm.sh) on
[Bubble Tea](https://github.com/charmbracelet/bubbletea) and
[Lip Gloss](https://github.com/charmbracelet/lipgloss). Single static binary,
no runtime to install.

## What's included

- **gum** — the binary. Fourteen subcommands in three groups:
  - *Interactive*: `input`, `write`, `confirm`, `choose`, `filter`, `file`,
    `table`, `pager` — each prompts on the terminal and prints the result.
  - *Non-interactive*: `style` (borders, padding, colour, alignment), `format`
    (markdown, code, emoji or Go templates), `join` (compose blocks
    horizontally or vertically), `log` (levelled, structured log lines).
  - *Utility*: `spin` (run a command under a spinner), `version-check` (test
    the running gum against a semver range).

## Quick start

```sh
NAME=$(gum input --placeholder "your name")
gum confirm "ship it?" && echo "shipping"

# menus write the choice to stdout
BRANCH=$(git branch --format='%(refname:short)' | gum filter)
git switch "$BRANCH"

# non-interactive rendering works in pipes and CI
gum style --border double --padding "1 2" --foreground 212 "done"
gum log --level warn "disk almost full" free=2GiB
```

Every visual knob is also an environment variable, so a script can be themed
without touching its call sites:

```sh
export GUM_INPUT_CURSOR_FOREGROUND="#FF0"
export GUM_CHOOSE_CURSOR_FOREGROUND="#0FF"
```

## Interactive commands need a terminal

`input`, `choose`, `filter`, `confirm`, `file`, `write`, `table` and `pager`
render a full-screen UI and read keystrokes: they need a tty. In CI, a cron
job, or any pipeline where stdin is not a terminal, use the non-interactive
side — `style`, `format`, `join`, `log`, `version-check` — which write plain
bytes to stdout and exit.
