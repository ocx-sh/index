# superfile

[superfile](https://superfile.dev) is a pretty fancy and modern terminal file
manager. It runs entirely in the terminal as a TUI: multiple file panels and
tabs side by side, a metadata sidebar, built-in preview for text, images and
directories, and batch rename, copy, move, delete and compress/extract
operations — all driven from the keyboard with Vim-style (and fully
customizable) hotkeys.

Configuration lives in plain TOML under the XDG config directory
(`spf path-list` prints every location), with 20+ bundled color themes and
support for custom ones. `spf --print-last-dir` integrates with the shell so
quitting superfile can `cd` you to the directory you navigated to.

## What's included

- **spf** — the superfile binary. `spf` opens the file manager in the current
  (or given) directory; `spf path-list` prints the config, hotkey, log and
  data paths; `--fix-hotkeys` / `--fix-config-file` repair a config after an
  upgrade; `--chooser-file <path>` turns superfile into a file picker for
  other programs.

## Install with ocx

```sh
ocx install ocx.sh/superfile/superfile
```

```sh
# or pin a specific version
ocx install ocx.sh/superfile/superfile:1.6.0
```
