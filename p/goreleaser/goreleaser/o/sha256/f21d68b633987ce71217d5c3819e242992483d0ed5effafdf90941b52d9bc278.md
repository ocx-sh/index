# goreleaser

[GoReleaser](https://github.com/goreleaser/goreleaser) turns a tagged commit
into a complete release. One `.goreleaser.yaml` describes the whole pipeline —
cross-compiled builds, archives, checksums, changelog, signatures, SBOMs,
container images, Linux packages, package-manager formulae — and a single
`goreleaser release` runs it end to end against GitHub, GitLab or Gitea.

Originally written for Go, it now builds Rust, Zig, TypeScript and Python
projects through the same configuration, and the same run publishes to
Homebrew, Scoop, Nix, Winget, AUR, apt/yum repositories and Docker registries
without a bespoke script per target.

## What's included

- **goreleaser** — the binary. `goreleaser init` writes a starter
  `.goreleaser.yaml`; `goreleaser check` validates one or more config files;
  `goreleaser healthcheck` reports which external tools your config needs;
  `goreleaser build --snapshot` compiles without publishing; `goreleaser
  release --snapshot --clean` runs the full pipeline against a scratch
  directory; `goreleaser release` cuts the real thing. `goreleaser jsonschema`
  emits the config JSON Schema for editor completion.

The archive also ships upstream's `LICENSE.md` and `README.md`, shell
completions for bash/fish/zsh under `completions/`, and the man page under
`manpages/`.

## Note on scope

This package mirrors the **open-source** GoReleaser distribution. GoReleaser
Pro is a separate, separately licensed product and is not mirrored here.

`goreleaser release` needs a git repository, a working toolchain for whatever
it builds, and credentials for whatever it publishes to. `goreleaser init`,
`check` and `jsonschema` need none of those.
