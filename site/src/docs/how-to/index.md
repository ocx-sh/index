# How-To

Task-oriented guides: announce a package, claim a namespace, yank a version.

- [Announce a Package](./announce-a-package) — open a fork PR announcing
  your curated tags, via the `ocx` CLI or by hand
- [Claim a Namespace](./claim-a-namespace) — first-claim PR flow,
  multi-owner supported
- [Yank a Version](./yank-a-version) — mark a tag row yanked
